# Colin McRae Rally Recomp
The PSX version of Colin McRae Rally (SCUS-94474) has now been statically recompiled using psxrecomp and claude.

# Why not play the pc version?

Because running the pc version on modern windows is a headache even with patches and decompiling it will take much longer then this project being finished.

# What do i need to run this recomp?

Your need your own legal PSX Colin McRae Rally (SCUS-94474) disc files. You dont need a bios file thanks to Openbios.

# How do i run it?

1. Run the scripts.
2. Follow the steps.
3. Once its finishes.

 If you want widescreen its in mods.

 # Found a bug?

 If you find a bug thats not mentioned report it in issues with your exact pc specs.
